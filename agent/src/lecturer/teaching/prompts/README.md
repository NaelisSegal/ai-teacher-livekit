# Prompts

The instructions given to the live teacher's models: `writer.md` (writes the class
as it is taught) and `planner.md` (reshapes the rest of the class at checkpoints).

They are one way to teach, the one this project is trying out: slow, with time to
think, problems worked step by step with the class. They are not the only way. To
use your own, put `writer.md` and/or `planner.md` in a folder and set
`CH_PROMPTS_DIR` to it: any file it has is used instead of the one here.

The lesson itself (what to teach, what can be cut, harder problems) belongs in a
lesson's teaching notes, not here: these are for how to teach any lesson.
